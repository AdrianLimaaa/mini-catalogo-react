# 🌱 Mini Catálogo de Plantas

Aplicação frontend desenvolvida em **React** para exibição e filtragem de plantas em uma interface responsiva e componentizada.

O projeto foi criado para praticar conceitos de desenvolvimento frontend, organização de componentes, manipulação de estado e experiência de usuário.

---

## 🚀 Tecnologias utilizadas

- React
- JavaScript
- Vite
- HTML
- CSS

---

## ⚙️ Funcionalidades

- Filtro por nível de exposição ao sol
- Filtro por frequência de rega
- Exibição de plantas em cards
- Modal com informações detalhadas
- Skeleton Loading
- Animações de entrada
- Layout responsivo

---

## 🧠 Conceitos aplicados

Durante o desenvolvimento do projeto, foram trabalhados conceitos como:

- Componentização
- React Hooks
- Manipulação de estado
- Renderização condicional
- Organização de componentes
- Responsividade
- Experiência de usuário
- Intersection Observer

---

## ▶️ Como executar o projeto

### Pré-requisitos

- Node.js
- npm

### Clone o repositório

~~~bash
git clone https://github.com/AdrianLimaaa/mini-catalogo-react.git
~~~

### Acesse a pasta

~~~bash
cd mini-catalogo-react
~~~

### Instale as dependências

~~~bash
npm install
~~~

### Execute o projeto

~~~bash
npm run dev
~~~
